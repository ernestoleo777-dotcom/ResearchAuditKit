# Release delta review

The public RC1 tag and release remain unchanged and do not contain the Phase 1
commands. The current source still declares version `0.1.0rc1`; that version
must not be republished with different contents.

The proposed future release identifier is `0.1.0rc2` with tag
`v0.1.0-rc.2`. This is planning only. No tag, release, package build for
publication, TestPyPI upload, or PyPI upload is authorized by this review.

The planned RC2 scope is limited to the three Phase 1 clean-room custody
commands, the P1 overwrite-guidance fix, their documentation, tests, and
acceptance evidence. It excludes controllers, scientific features, and any new
capability.
