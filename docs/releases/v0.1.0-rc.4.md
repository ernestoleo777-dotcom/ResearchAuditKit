# ResearchAuditKit v0.1.0-rc.4

RC4 introduces the explicit asset → evidence → claim workflow to the release.

- Guided asset-list authoring: `rak evidence wizard` (preview/confirmation).
- Capture graph identities with `rak evidence init`.
- Trace declared claim impact with `rak evidence impact`.
- Gate an anchored baseline with `rak evidence check`.
- GitHub-readable reports: `--format markdown`, including Job Summary guidance.
- Stable hashing improvements and first-party candidate build evidence checks.

Install the wheel from this GitHub prerelease and verify it against SHA256SUMS.
The release manifest records the exact source commit and artifact hashes. RC3 and
its immutable assets remain unchanged. No PyPI/TestPyPI upload is part of RC4.

Claims and relationships are user declarations. A mechanical PASS does not
establish scientific correctness, authenticity or reproducibility. Captures and
checks are bounded observations, not atomic multi-file snapshots. This release
adds no independent external consumer or new scientific acceptance claim.

See the onboarding and anchored-check guides in the source distribution.
