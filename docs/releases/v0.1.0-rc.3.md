# ResearchAuditKit v0.1.0-rc.3

## Overview

RC3 is an experimental GitHub prerelease of a local-first release-engineering
and integrity toolkit for ML research repositories. It introduces the unified
`AUDIT → FREEZE → VERIFY → GATE` product workflow while preserving the existing
command surface. There is no stable release and no PyPI, TestPyPI, or GitHub
Marketplace publication.

## Highlights

- Add zero-configuration `rak audit [PATH]` with optional explicit project
  policy support.
- Emit deterministic human output and canonical
  `researchauditkit.audit/v1` JSON without timestamps or host-absolute target
  paths.
- Reject absolute, traversing, non-canonical, and symlink-escaping
  `policy.required_files` entries before inventory or hashing, without
  disclosing rejected values.
- Add a self-bootstrapping composite GitHub Action at the exact versioned ref
  `ernestoleo777-dotcom/ResearchAuditKit@v0.1.0-rc.3`.
- Preserve every existing command, policy, schema, and valid-policy output
  contract.

## GitHub Action boundary

The Action provisions SHA-pinned `actions/setup-python`, fixed Python 3.12.14,
and hash-locked PyYAML 6.0.3. Bootstrap therefore requires GitHub Action and
Python package infrastructure. Repository analysis then runs locally on the
runner: repository contents are not uploaded, target-project dependencies are
not installed, and target-project code is not executed. No hosted
ResearchAuditKit service is required.

No mutable `v0`, `v0.1`, `main`, or `latest` Action alias is published. Users
seeking maximum immutability may pin the annotated tag's resolved commit SHA.

## Compatibility evidence

The release commit is gated by the complete test suite on Ubuntu with Python
3.10, 3.11, and 3.12, plus end-to-end execution of all eight composite-Action
scenarios. Existing Node.js runtime and `punycode` deprecation warnings from
upstream Actions remain known warnings; they are not functional failures and
were not changed for RC3.

## Installation

Install the verified wheel from this GitHub prerelease and check it against the
published `SHA256SUMS` and `RC3_RELEASE_MANIFEST.json`:

```bash
python -m pip install \
  "https://github.com/ernestoleo777-dotcom/ResearchAuditKit/releases/download/v0.1.0-rc.3/research_audit_kit-0.1.0rc3-py3-none-any.whl"
rak --version
```

## Adoption and non-claims

CoordCap remains the one verified, self-owned public consumer through its RC2
CLI integration. It is not independent adoption and is not evidence of RC3
Action consumption. The independent external consumer count remains zero.

ResearchAuditKit makes mechanical observations over local files and declared
policies. It does not certify scientific correctness, reproducibility,
replicability, paper validity, peer-review acceptance, or claim truth.

## Release assets

The prerelease attaches exactly four custom assets: the wheel, sdist,
`SHA256SUMS`, and `RC3_RELEASE_MANIFEST.json`. The manifest binds the merge
commit, tree, CI evidence, build environment, filenames, sizes, and SHA-256
values. No cross-build byte-reproducibility claim is made.
