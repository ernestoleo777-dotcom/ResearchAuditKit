# Migration Provenance

The toolkit's high-level concepts were inspired by the governance process of an archived internal project. No data, paper, result table, model, engineering claim, source implementation, comment, fixture, or private filesystem path from that project was migrated. APIs and code were independently designed from generic behavioral requirements, and every test/example uses newly authored synthetic fixtures.

This repository is an independent reproducibility-engineering tool and is not a continuation of the archived project.
