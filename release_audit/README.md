# Release Candidate Audit

This directory is the evidence bundle for Phase 1 release hardening of ResearchAuditKit 0.1.0. It records the pre/post source manifests, package builds, isolated installations, CLI and documentation execution, safety reviews, CI configuration, and the RC1 decision.

The audit is engineering evidence, not a scientific validation or third-party security certification. Distribution artifacts remain local under the ignored `dist/` directory and were not uploaded. Phase 0 evidence under `audit/` was treated as immutable.

The current engineering status is `RELEASE_CANDIDATE_READY`. Public release remains `BLOCKED_BY_LICENSE_SELECTION`.
