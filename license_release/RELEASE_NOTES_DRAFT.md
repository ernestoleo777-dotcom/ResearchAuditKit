# ResearchAuditKit v0.1.0-rc.1

This pre-release provides local repository-integrity inventory and verification, versioned baselines, empirical marginal, joint, and conditional support audits, Pareto contamination diagnostics, split/leakage metadata audits, governance gates, claim matrices, protocol-deviation records, negative-result preservation, a local CLI, and synthetic examples.

It includes Apache-2.0 licensing and packaging metadata, plus Python 3.10-compatible TOML parsing for release-metadata tests. CI covers Python 3.10, 3.11, and 3.12.

This is a pre-release engineering utility, not a scientific method or benchmark. It does not establish scientific correctness or physical feasibility; empirical support is not physical feasibility; metadata leakage checks can remain unverified; and local manifests can contain filenames and hashes that should be reviewed before sharing. It does not guarantee complete leakage detection or publication acceptance.
